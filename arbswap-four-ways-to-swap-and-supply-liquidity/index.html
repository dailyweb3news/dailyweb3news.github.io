Arbswap: four ways to swap and supply liquidity

Arbswap connects token swaps, liquidity pools, farming and cross-network trades on Arbitrum, but each route suits a different job and carries its own trade-offs.

The Onchain Brief EditorsOct 20, 2026 · 20:11 UTC3 min read

The arbswap setup gives users four ways to trade or put tokens to work: swap on one network, add liquidity, farm a pool position, or move assets between networks. Arbswap is a decentralised exchange, where trades run through smart contracts and token pools. Its current public pages describe activity on Arbitrum One and Arbitrum Nova, with cross-network swaps powered by Symbiosis. I refer to arbswap here because the name is useful shorthand for this set of options.

How does an Arbswap token swap work?

A token swap trades one asset for another using a pool of tokens, rather than matching buyers and sellers in an order book. The price comes from the pool’s available balances, so a small pool can give a worse rate for a large trade. Before signing, check the output amount, the network shown in your wallet and the transaction fee. A low network fee does not guarantee a good price.

For a simple trade, use the same network where your tokens already sit. Arbitrum One and Nova are separate networks, even though both belong to the Arbitrum family. A token on one does not automatically count as the same token on the other.

What does adding liquidity to Arbswap involve?

Adding liquidity means depositing tokens into a pool so other people can trade them. In return, providers may receive a share of trading fees. The pool usually needs a pair of assets, and each deposit exposes the provider to changes in their relative prices. This can leave the value of the position below what simply holding the tokens would have produced.

For a first position, look at the exact pool, its trading activity and the rules for removing funds. A pool with little use may generate few fees. Arbswap’s public pages describe liquidity farming for pool providers, but the available pool choices and current rewards can change.

Should you choose flexible or locked farming?

Farming means staking a pool position to earn extra rewards. Arbswap describes both flexible and locked farming. Flexible positions are easier to withdraw; locked positions tie up the position for a set period, in exchange for the possibility of higher rewards. Those rewards can change in value, so a bigger advertised rate is not a sure profit.

  • Choose a swap if you only need to exchange tokens.
  • Add liquidity if you want to support trading and accept pool price risk.
  • Consider flexible farming if access to your position matters.
  • Consider locked farming only if you can leave the position untouched for the lock period.

When does an Arbswap cross-network swap help?

A cross-network swap combines exchanging tokens with moving them between supported networks. Arbswap says its Symbiosis integration can move assets between Arbitrum One and Nova in one transaction. That can save separate steps, but the route depends on supported assets and available liquidity. Check the destination network and the final amount before confirming.

The practical choice is simple: trade on the network holding your tokens when you can, add liquidity only when you understand the pool, and treat farming rewards as uncertain. Use a cross-network route when moving networks is part of the job, not just because it appears to be one step.
