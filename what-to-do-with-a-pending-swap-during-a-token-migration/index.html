What to Do With a Pending Swap During a Token Migration

A pending swap may be waiting on the network, a bridge, or a new token contract. Check its status before you retry, cancel, or move funds.

The Onchain Brief EditorsOct 16, 2026 · 13:20 UTC3 min read

If a swap is pending during a token migration, first find out whether the transaction was sent, confirmed, or never completed. A migration can change which token contract a swap uses, but it does not erase a transaction already recorded on a blockchain. Check the transaction in your wallet’s activity or the relevant block explorer, a site that shows on-chain activity.

If the route itself is still in question, read this guide to choosing a QuickSwap route, which compares swapping directly with bridging first. The right next step depends on where your transaction stopped.

Why can a swap stay pending during a migration?

A swap can stay pending because the network has not yet included it in a block. On some networks, this happens when the fee offered is too low for current demand. The swap may also be waiting for a separate step, such as a bridge transfer or a token approval.

A token migration usually means moving from an old token contract to a new one. A contract is the on-chain code that tracks a token and handles its transfers. The project may provide a migration tool, but that does not automatically change the token address in a pending swap. Until the swap finishes, the old transaction may still be trying to trade the old token.

Check the transaction status and the token address shown by the project’s official migration instructions. A wallet label or ticker can be misleading when old and new tokens share a name.

Should you cancel or retry a pending swap?

Do not submit the same swap again until you know what happened to the first one. If it is still pending, a second swap could also go through, leaving you with two trades. If it has failed, check whether the network charged a fee and whether any token approval remains active.

On some networks, a wallet can replace a pending transaction or send a cancellation using the same account sequence number. This is often called the nonce, a number that orders transactions from one account. Replacement rules vary by network and wallet, and a cancellation may fail if the original transaction has already been confirmed. Check the wallet’s instructions before using either option.

  • Pending: wait or review the wallet’s fee and replacement options.
  • Confirmed: check the result and token balances before taking another action.
  • Failed: confirm the failure on-chain, then decide whether to retry with the correct token contract.
  • Bridge in progress: check the bridge’s transfer status before starting another transfer.

What should you check before swapping after migration?

Use the project’s official migration instructions to confirm the new token contract and the supported network. Make sure the swap page shows that contract, not just the expected ticker or logo. If the migration requires a separate claim or conversion, complete that step before attempting a swap.

For most readers, the safest course is to wait until the first transaction has a clear status, then act once using the confirmed migration route. A pending label alone does not show whether funds are lost or safe to spend again. The transaction record does.
