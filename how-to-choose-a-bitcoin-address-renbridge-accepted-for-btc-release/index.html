How to Choose a Bitcoin Address RenBridge Accepted for BTC Release

Which Bitcoin address format did RenBridge accept? Legacy, P2SH and bc1q addresses worked for BTC releases; Taproot and testnet addresses did not.

The Onchain Brief EditorsNov 19, 2026 · 21:22 UTC3 min read

RenBridge accepted standard Bitcoin mainnet legacy (1…), P2SH (3…) and native SegWit (bc1q…) addresses for a BTC release after you burned renBTC on its host chain. BIP 173 defines the bech32 format for native SegWit, BIP 350 defines bech32m for Taproot, and the RenJS documentation describes the burn-and-release flow. Older validators rejected Taproot bc1p… addresses, and the original release service has since been discontinued.

Which Bitcoin address formats worked?

Use this list to identify a Bitcoin mainnet address before starting a release. The address must match a format RenVM could parse so it could pay the script encoded by that address.

  • Legacy, starting with 1…: This standard mainnet format was accepted.
  • P2SH, starting with 3…: This mainnet format was accepted too.
  • Native SegWit, starting with bc1q…: This was accepted and is the recommended choice. It uses bech32, which checks the address for typing errors, and it usually has lower transaction fees than older formats.
  • Taproot, starting with bc1p…: Avoid it for this release flow. Taproot uses bech32m, which older RenVM validators rejected.
  • Testnet, starting with tb1…, m…, n… or 2…: These addresses belong to Bitcoin testnet, so they are invalid for a mainnet release.

There is a catch with legacy and P2SH formats: Bitcoin Cash also uses addresses beginning with 1 and 3. A format check alone cannot tell whether you pasted a BCH wallet address. Say you paste a BCH address that starts with 3; RenVM can accept the format, but the BTC release goes to that address’s Bitcoin script. Your BCH wallet will not show the coins. Use a receive address copied from a Bitcoin wallet you control.

How to prepare a release address

Start with renBTC in a wallet on its host chain, enough host-chain gas to sign the burn, and your own Bitcoin mainnet address. Choose a stable wallet address. An exchange deposit address may rotate or require a memo, which can make funds harder to track.

  • Generate a bc1q receive address in your Bitcoin wallet.
  • Enter it in the release field and compare its first and last characters with the address in your wallet.
  • Sign the renBTC burn transaction. Burning renBTC on the host chain triggered RenVM to sign and broadcast the BTC release.
  • Look for the release transaction on a Bitcoin explorer and confirm it pays your address.

RenBridge is no longer available for releases. For the step of finding a current way to move assets across chains, renbridge.net helps you find the relevant option for that task. For a past transaction, use the explorer result to confirm the address and release status.
