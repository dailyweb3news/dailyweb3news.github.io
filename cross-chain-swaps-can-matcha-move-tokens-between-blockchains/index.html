Cross-chain swaps: Can Matcha move tokens between blockchains?

Can I swap tokens between blockchains on Matcha swap? Yes. Choose supported networks and tokens, review what you’ll receive, sign once, then wait for delivery.

The Onchain Brief EditorsNov 19, 2026 · 05:28 UTC3 min read

Matcha swap is a decentralized exchange aggregator that can help you exchange a token on one blockchain for a token on another in a single cross-chain swap. Matcha swap combines a token swap with a bridge route behind one quote. Yes, you sign once on the source chain, then wait for the destination token to arrive.

How to swap tokens between blockchains on Matcha

Take a swap from USDC on Ethereum to ETH on Arbitrum. Choose Ethereum as the source network and USDC as the token to sell, then choose Arbitrum and ETH as the destination. The route must be available for those networks and tokens. Available chains can change; 0x’s supported-chain reference shows why network support is route-dependent.

Read the quote before signing. It combines the swap price, bridge fee and gas on the source chain. Pay attention to the minimum amount you’ll receive on Arbitrum, since that tells you the least the route expects to deliver under the quoted terms.

You need gas on Ethereum to start this example. You do not need Arbitrum gas just to receive the ETH, but you will need Arbitrum’s gas token for a later transaction there. Network fees are paid on the network where the transaction runs; Ethereum.org’s explanation of gas describes the Ethereum side of that cost.

After signing, the wallet shows the Ethereum transaction as confirmed before the destination funds arrive. That confirmation means the source transaction has been processed; it does not mean the cross-chain delivery is complete. Wait for the ETH on Arbitrum and use the destination chain’s explorer to track its arrival.

Before starting, make sure the destination address is one you control on Arbitrum. This matters if you use a smart-contract wallet such as Safe: it may not control the same address on the destination chain. Set a recipient you know you can access there, or use a regular wallet address. The swap is ready to start when the route is available, the quote shows the destination minimum, and the recipient is correct.

Related questions

How long does a Matcha cross-chain swap take?

A Matcha cross-chain swap takes longer than a same-chain swap because delivery depends on the bridge route. Wait time varies by route. The source transaction can show as confirmed while the destination transfer is still underway, so use the destination explorer to check for arrival.

What fees does a cross-chain swap include?

The quote bundles the swap price, bridge fee and source-chain gas. Review the minimum destination amount alongside those costs before signing. You need gas on the source network to begin; a later transaction on the destination network needs that network’s gas token.

Questions to check before you swap

Which bridges does Matcha swap use for cross-chain swaps?

The route determines which bridge service handles delivery, and the available route can vary by network pair and tokens. Review the route and quote shown for your intended swap before signing. If no route is available, you’ll need to choose a different supported network or token pair.

What do I do if my cross-chain swap never arrives?

First, check the source transaction on its network’s explorer and confirm it succeeded. Then look for the destination transaction or funds on the destination explorer. If the source is confirmed but delivery is still pending, keep the transaction details and use the route’s stated tracking or support path to investigate. If the recipient address was a Safe address, verify that you control it on the destination chain. Recheck the route and recipient before trying again; the answer may change if route availability changes.
