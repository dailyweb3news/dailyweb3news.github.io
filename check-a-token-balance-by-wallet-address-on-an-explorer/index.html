Check a Token Balance by Wallet Address on an Explorer

To check a token balance by wallet address, search the right chain’s explorer, match the token contract and read its quantity; query balanceOf if the listing is missing or stale.

The Onchain Brief EditorsNov 18, 2026 · 21:46 UTC3 min read

A token balance belongs to a wallet address on one blockchain, so search that address on the matching explorer, find the token by contract address and read its quantity. The address, chain and contract must match; the displayed units should then show the current token quantity.

Have the public wallet address, the chain it is on and the trusted token contract address ready. You do not need to connect a wallet to view an address on an explorer.

For a lifi bridge transfer, look up the destination address on the destination chain. To confirm a lifi bridge transfer arrived, use that same address and chain before checking the token holding.

Find the token holding

  1. Open the relevant chain’s block explorer, such as Etherscan for Ethereum, and paste the public address into its search bar. The address page appears without asking you to connect your wallet.
  2. Open the address’s token holdings or assets section. Find the token using its contract address, rather than relying on the name or symbol, which may be shared by different tokens. The matching row identifies the contract and its quantity. Etherscan’s Token Holdings lists both the contract address and quantity columns (Etherscan Token Holdings).
  3. Read the Quantity for the matching contract. For instance, after a lifi bridge transfer, the destination chain’s holding shows how many of that token the destination address has. A token balance can differ between chains, so a quantity shown on the source chain is not the destination balance.
  4. Compare the displayed quantity with the address, chain and contract you intended to check. When all four details—the address, chain, contract and displayed units—match, you have the current balance shown by the explorer.

Query the contract if the holding is missing or stale

An explorer’s holdings list can lag behind a contract’s actual balance. Some token contracts do not emit the transfer events explorers use to update their holdings, so a row may be missing or its quantity may be out of date.

  1. Open the trusted token contract page on the same chain and select its verified Read Contract tab. Find balanceOf, the ERC-20 function that returns an address’s raw token balance. Enter the public wallet address and query it. Etherscan describes this direct lookup for checking a current balance (Etherscan on non-standard tokens).
  2. Convert the raw result into displayed token units using the token’s decimals value. Divide the raw balance by 10 raised to the decimals value. For instance, with 6 decimals, divide by 10⁶. The result is the human-readable quantity; compare it with the holding row when that row is available.
